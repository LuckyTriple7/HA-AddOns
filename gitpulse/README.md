# GitPulse

**GitHub Control Panel für Home Assistant**

Zeigt Pull Requests, Issues, CI-Status und neue Releases auf einen Blick — direkt im HA-Dashboard.

## Features

- Pull Requests & Issues deiner eigenen Repos
- CI/Actions Workflow-Status
- Release-Tracker für beliebige Repos (inkl. HA Beta/RC)
- Browser-Benachrichtigungen bei neuen Releases
- Telegram-Benachrichtigungen (optional)
- PWA — installierbar, auch hinter Cloudflare Tunnel
- Dark / Light Mode
- Passwortschutz mit Bruteforce-Erkennung

## Setup

1. GitHub Fine-Grained PAT erstellen (siehe DOCS.md)
2. Token + Repos in den Add-on-Einstellungen konfigurieren
3. Add-on starten — Port 17792
