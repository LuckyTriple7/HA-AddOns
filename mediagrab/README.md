# MediaGrab

**yt-dlp Web-GUI für Home Assistant** — Videos und Audio von YouTube, Vimeo, SoundCloud, TikTok und hunderten weiteren Seiten herunterladen.

## Features

- Passwortgeschützte Web-Oberfläche mit Brute-Force-Schutz
- Format-Auswahl: MP4 (Best/1080p/720p/480p/360p), MP3, M4A
- Live-Fortschrittsanzeige mit Geschwindigkeit und ETA
- Playlist-Support und optionale Untertitel
- Datei-Browser für gespeicherte Medien
- Dark Mode / Light Mode
- Mehrsprachig: Deutsch & Englisch
- PWA-fähig (als App installierbar)
- Speicherort: `/media/mediagrab`

## Konfiguration

Benutzername, Passwort und weitere Optionen werden in der Add-on-Konfiguration gesetzt.

## Unterstützte Seiten

Alle von [yt-dlp](https://github.com/yt-dlp/yt-dlp) unterstützten Seiten (YouTube, Vimeo, SoundCloud, TikTok, Twitch, u.v.m.).
