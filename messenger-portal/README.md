# MessengerPortal

[![Version](https://img.shields.io/badge/version-0.0.1-blue)](CHANGELOG.md)

Zentrale, passwortgeschützte Startseite für WhatsApp-, Telegram- und Signal-Add-ons.

## Features

- 🔒 Passwortgeschützter Login mit konfigurierbarer Session-Dauer
- 💬 Direkter Zugriff auf alle Messenger per Klick
- 🌙 Dark / Light Mode (automatisch + manuell)
- 🌍 Deutsch & Englisch (automatische Spracherkennung)
- 📱 Responsive Design & PWA-fähig
- ⚙️ Vollständig konfigurierbar über HA-Add-on-Optionen
