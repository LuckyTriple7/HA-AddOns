# MessengerPortal

[![Version](https://img.shields.io/badge/version-0.0.1-blue)](CHANGELOG.md)

Zentrale, passwortgeschützte Startseite für WhatsApp-, Telegram- und Signal-Add-ons.

## Features

- 🔒 Passwortgeschützter Login mit konfigurierbarer Session-Dauer
- 💬 Direkter Zugriff auf alle Messenger per Klick
- 🌙 Dark / Light Mode (automatisch + manuell)
- 🌍 Deutsch & Englisch (automatische Spracherkennung)
- 📱 Responsive Design & PWA-fähig
- 📤 „Senden an“: Inhalte aus dem Teilen-Menü direkt an einen WhatsApp-, Telegram- oder Signal-Chat schicken – oder in den eigenen Status/die eigene Story
- 🗂️ Status-Ablage: Bilder, Videos und Text über den Tag sammeln (auch per Teilen vom Handy), automatisch verkleinern und als Status/Story an WhatsApp, Telegram und Signal posten – sofort oder geplant
- 🪞 Status-Spiegel: eigene WhatsApp-Statusmeldungen automatisch als Signal- und/oder Telegram-Story übernehmen
- ⚙️ Vollständig konfigurierbar über HA-Add-on-Optionen
