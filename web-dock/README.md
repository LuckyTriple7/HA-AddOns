# WebDock

Passwortgeschützter Startportal für bis zu 10 interne Web-Dienste in Home Assistant.

## Features

- Bis zu 10 interne Dienste (IP + Port) konfigurierbar
- Online-Status (grüner/roter Punkt) per TCP-Port-Check
- Eigene PNG-Icons aus dem addon_config-Ordner
- Eingebauter Reverse-Proxy (nginx) mit WebSocket-Unterstützung
- Drag-fähiger „Zurück zum Portal"-Button auf allen Proxy-Seiten
- Dark/Light-Mode, DE/EN Sprachauswahl
- PWA-fähig (als App installierbar)
- Rate Limiting gegen Brute-Force-Logins

## Installation

Repository in Home Assistant hinzufügen und das Add-on installieren.
