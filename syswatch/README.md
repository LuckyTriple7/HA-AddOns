# HA SysWatch

Docker container resource monitor for Home Assistant.

Displays CPU, RAM, Network I/O, and Disk I/O for all Docker containers
in a sortable, PWA-ready web interface.

## Features

- Sortable table with CPU %, RAM %, NET I/O, DISK I/O, PIDs
- CPU sparkline history per container
- Log viewer and container restart from the UI
- Password-protected with brute-force lockout
- DE / EN language support
- PWA — installable on desktop and mobile
- Mobile-responsive dark theme

`17790`
